# Eris Chat

Клиент для общения с Эрис на Windows: текст, голосовые сообщения и озвучка ответов.

**[Скачать актуальную версию](https://github.com/HartForj/eris-client-releases/releases/latest)**

1. Скачайте файл `Eris-Chat_…_x64-setup.exe` из последнего выпуска.
2. Установите и откройте Eris Chat.
3. Вставьте персональное приглашение от владельца Эрис.

Адрес сервера уже включён в приглашение. Код нужно активировать в течение 24 часов после выдачи; после активации приложение сохраняет доступ на этом устройстве. Не публикуйте приглашения в общем чате.

В приложении можно писать сообщения, записывать речь и слушать ответ. Сервер должен быть включён; обработка реплики может занять время. Новые версии предлагаются в самом приложении кнопкой «Обновить».

В этом репозитории размещаются установщики, подписи обновлений, контрольные суммы и описание изменений.
